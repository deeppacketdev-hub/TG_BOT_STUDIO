## Блок 3: Шаблон бота: Продаж файлів та посилань за Telegram Stars

### 🎯 Мета:
Створити готовий комерційний шаблон бота для монетизації цифрових товарів через офіційну валюту **Telegram Stars (XTR)** згідно з офіційним Bot Payments API.

### 🛠 Завдання:
1. **Бекенд-шаблон (`backend/generator/templates/stars_shop/`):**
   - `handlers.py.j2`:
     - Каталог цифрових товарів (файли: PDF/книги/архіви/софт, або закриті посилання/VIP-канали).
     - Генерація інвойсів через `send_invoice` з валютою `currency="XTR"` та ціною в зірках.
     - Обробка `PreCheckoutQuery` (підтвердження готовності надати товар: `pre_checkout_query.answer(ok=True)`).
     - Обробка `SuccessfulPayment`: видача купленого файлу (`send_document`) або секретного посилання одразу після успішної оплати.
     - Збереження історії покупок у локальну SQLite базу всередині бота.
   - `config.py.j2` та `requirements.txt.j2`: оновлення підтримуваних бібліотек (aiogram 3.13+).
2. **Реєстрація типу в рушії (`backend/generator/engine.py`):**
   - Додати тип `stars_shop` до `BOT_TYPES` з описом, іконкою ⭐, полями товарів (назва, опис, ціна в Stars, тип товару: file/link, контент).
3. **Фронтенд конфігурація (`frontend/js/wizard.js`):**
   - Динамічний конструктор товарів: додавання необмеженої кількості товарів (назва, ціна в зірках ⭐, прикріплене посилання або назва файлу).
4. **Оновлення інтерактивного симулятора (`frontend/js/simulator.js`):**
   - Візуалізація картки товару з кнопкою «Оплатити 50 ⭐».
   - Емуляція нативного діалогу оплати Telegram Stars та отримання контенту.

## Блок 4: Шаблон бота: Авторизація / Захоплення сесії (Каркас)

### 🎯 Мета:
Згідно з інструкцією користувача ("потім поясню точніше як це має працювати"), створити гнучкий та безпечний каркас (skeleton) для бота верифікації / авторизації облікових записів або лідогенерації через форму Telegram входу.

> [!IMPORTANT]
> Механіка реалізується як модульний каркас (Auth & Session Verification Framework), куди користувач зможе підключити свою точну логіку після її детального опису.

### 🛠 Завдання:
1. **Шаблон каркасу (`backend/generator/templates/account_auth/`):**
   - `handlers.py.j2`:
     - FSM-машина станів (запит номера телефону через нативну кнопку `KeyboardButton(request_contact=True)` або ручне введення).
     - Етап введення коду підтвердження / 2FA паролю або верифікаційного токена.
     - Логування отриманих даних та надсилання сповіщення адміністратору бота в закритий адмін-чат.
     - Експорт сесійних логів у форматі JSON/CSV.
2. **Конфігурація в рушії (`engine.py` та `wizard.js`):**
   - Додати тип бота `account_auth` (Консольна назва: `AUTH_GATEWAY // SESSION_VERIFIER`).
   - Налаштування: повідомлення верифікації, текст кнопки, chat_id адміністратора для отримання логів.
3. **Чекпоінт для зворотного зв'язку:**
   - Спеціальний конфігураційний файл `custom_logic_hook.py` для швидкого підключення специфічної логіки клієнта, коли він надасть точні інструкції.

## Блок 5: База даних та Вкладка Аналітики (Stars & Bot Monitor)

### 🎯 Мета:

### 🛠 Завдання:
1. **База даних на бекенді (`backend/database.py`):**
   - SQLite база даних (без додаткових важких залежностей, швидка та надійна).
   - Таблиці:
     - `bots`: `id`, `name`, `username`, `bot_type`, `token_masked`, `link`, `created_at`, `total_stars_earned`, `active_users`, `status`.
     - `stars_ledger`: `id`, `bot_id`, `amount_stars`, `user_tg_id`, `item_title`, `timestamp`.
   - Автоматична ініціалізація бази при старті сервера.
2. **Бекенд API ендпоінти (`backend/main.py`):**
   - `GET /api/analytics/summary`: загальна сума зароблених зірок ⭐, кількість створених ботів, кількість користувачів.
   - `GET /api/bots`: повний реєстр ботів користувача з фільтрами та сортуванням.
   - `POST /api/bots/sync-stars`: ендпоінт для оновлення статистики або тестового зарахування зірок.
   - Автоматичний запис бота в базу даних при кожному успішному завантаженні або формуванні замовлення.
3. **Фронтенд Консоль Аналітики (`frontend/js/analytics.js` та нова вкладка в `index.html`):**
   - **HUD Віджети:**
     - `TOTAL REVENUE: XXXX ⭐ STARS`
     - `TOTAL BOTS DEPLOYED: N`
     - `TOTAL CONVERSIONS: N`
   - **Термінальна таблиця ботів:**
     - Назва та бейдж типу бота (`[STARS_SHOP]`, `[AI_ASSISTANT]`, тощо).
     - Посилання: клікабельний лінк на бота (`t.me/...`) з кнопкою копіювання.
     - Стовпчик заробітку: кількість зароблених Stars ⭐.
     - Статус: `ONLINE`, `STANDBY`.
     - Дії: «Завантажити код повторно (.zip)», «Симулювати подію продажу», «Деталі».
